## 🎯 API endpoints (полные)

### Аутентификация `/api/auth`
```
POST   /register              - Регистрация
POST   /login                 - Вход
GET    /profile               - Профиль
GET    /balance               - Баланс
PUT    /profile               - Обновить профиль
```

### Боксы `/api/boxes`
```
GET    /                      - Все боксы
GET    /:boxId                - Конкретный бокс
POST   /open                  - Открыть бокс
GET    /history/user          - История пользователя
GET    /leaderboard/wins      - Топ побед
```

### Платежи `/api/payment`
```
POST   /create-payment        - Создать платеж
POST   /webhook/yookassa      - Webhook ЮКассы
GET    /status/:paymentId     - Статус платежа
GET    /history               - История платежей
```

### Администрирование `/api/admin`
```
POST   /boxes                 - Создать бокс
PUT    /boxes/:boxId          - Обновить бокс
DELETE /boxes/:boxId          - Удалить бокс
POST   /prizes                - Создать приз
PUT    /prizes/:prizeId       - Обновить приз
GET    /stats                 - Статистика
GET    /logs                  - Логи системы
```

## 💡 Ключевые особенности

### 🎰 Система рулетки (контролируемая!)

```
Каждый приз имеет % вероятность выпадения:
Пример:
  iPhone 15    - 15%
  PlayStation  - 15%
  AirPods      - 70%
              -------
  ИТОГО = 100%

Меняете % в админ-панели → система меняется в реальном времени!
```

**Контроль:** Админ-панель → "⚙️ Управление вероятностями"

### 💰 Управление прибыльностью

```
Бокс стоит 1000₽
Средняя стоимость приза = 5000₽
Коэффициент = 5x (5000/1000)
Прибыль на один открытый бокс = 1000₽

Все контролируется через вероятности! 📊
```
