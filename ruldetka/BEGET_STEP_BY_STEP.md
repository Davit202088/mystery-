1. Откройте браузер (Chrome, Firefox, Safari)
2. Перейдите на **https://beget.com**
3. Найдите кнопку **"Вход"** в верхнем правом углу
4. Нажмите на нее

```
Экран Beget:
┌─────────────────────────────────────────┐

│                                         │
│   Пожалуйста, нажмите: [Вход]          │

└─────────────────────────────────────────┘
```

5. Введите ваш **логин** (почта или логин)
6. Введите ваш **пароль**
7. Нажмите **"Вход"**

Вы увидите личный кабинет Beget. Это может выглядеть примерно так:

## 🎯 Шаг 3: Создание Node.js приложения на Beget

### Где найти:

1. В левом меню найдите **"Управление"** или **"Мои приложения"**
2. Нажмите на **"Приложения"** или **"Создать приложение"**

```
Левое меню Beget:
┌──────────────────────┐
│ 📊 Мои услуги        │
│ ⚙️ Управление        │
│  └─ 📋 Приложения  ◄─┼─ НАЖМИТЕ ЗДЕСЬ
│  └─ 🗄️ БД          │
│  └─ 📁 FTP          │
└──────────────────────┘
```

### Создание приложения:

3. Нажмите кнопку **"Создать приложение"** или **"+"**
4. Выберите **"Node.js"** (не Express, не другое - именно Node.js)

```
Выбор типа приложения:
┌─────────────────────┐
│ PHP                 │
│ Node.js      ◄─ ВЫБЕРИТЕ ЭТОТ
│ Python              │
│ Ruby                │
└─────────────────────┘
```

5. Выберите версию Node.js:
   - Лучше выбрать **14.x** или **16.x** или **18.x** (новую версию)
   - Нажмите **"Далее"**

6. Укажите имя приложения:
   - Поле "Имя приложения": напишите `ruldetka` или `mystery-boxes`
   - Нажмите **"Далее"**

```
┌─────────────────────────────────────┐
│ Имя приложения:                     │
│ [ruldetka              ]            │
│ (можно использовать только буквы,   │
│  цифры и дефис)                    │
└─────────────────────────────────────┘
```

7. Выберите порт (порт - это "дверь" через которую приложение принимает запросы)
   - Обычно Beget предложит **3000** - это хорошо
   - Нажмите **"Создать"**

### Результат:

Beget создаст папку для вашего приложения и выдаст вам FTP доступ.

**Запомните эту информацию:**
- 📝 Имя приложения: `ruldetka` (или как вы назвали)
- 🔗 URL: что-то типа `https://ruldetka.beget.com` или `https://app.beget.com/ruldetka`

## 📁 Шаг 4: Загрузка файлов через FTP

FTP - это как облако, но старое. Мы будем загружать файлы на сервер через FTP.

### Вариант A: Через Beget панель (САМЫЙ ПРОСТОЙ)

1. В кабинете Beget найдите раздел **"Управление приложением"** или **"Файлы"**
2. Вы должны увидеть список файлов и папок приложения:

```
ruldetka/ (папка приложения)
├── app.js (или другой главный файл)
├── package.json
└── public/
```

3. Удалите все файлы (нажав кнопку "Выбрать все" → "Удалить")
4. Нажмите на кнопку **"Загрузить файлы"** или **"Upload"**
5. Найдите на вашем компьютере папку `C:\Users\user\ruldetka\`
6. Выберите ВСЕ файлы и папки внутри (не саму папку `ruldetka`, а содержимое)
   - `server.js`
   - `package.json`
   - папку `routes`
   - папку `middleware`
   - папку `public`
   - папку `database`
   - и т.д.
7. Нажмите **"Загрузить"**
8. Дождитесь когда все загрузится (может быть от 30 секунд до 2 минут)

### Вариант B: Через FTP клиент (если панель не работает)

Если в панели нет загрузки файлов:

1. Скачайте **FileZilla** (бесплатная программа для FTP)
   - Перейдите на https://filezilla-project.org/
   - Нажмите "Download"
   - Установите программу

2. Откройте FileZilla

3. В верхней части введите данные для подключения:
   - **Host:** `ftp://вашхостинг.beget.com` (Beget выдаст вам точный адрес)
   - **Username:** ваш логин Beget
   - **Password:** ваш пароль Beget
   - **Port:** 21 (обычно по умолчанию)

4. Нажмите **"Быстрое соединение"**

5. Слева (Local) найдите `C:\Users\user\ruldetka\`

6. Справа (Remote) найдите папку `ruldetka` (ваше приложение)

7. Выберите все файлы слева и нажмите **"Загрузить"**

```
FileZilla интерфейс:

Локальный компьютер (слева)    │    Сервер Beget (справа)
C:\Users\user\ruldetka\          │    /home/u12345/ruldetka/
├── server.js               -->  │    ├── server.js
├── package.json            -->  │    ├── package.json
├── routes/                 -->  │    ├── routes/
└── public/                 -->  │    └── public/
```

## 🗄️ Шаг 5: Создание БД и таблиц

### Где найти:

1. В левом меню Beget найдите **"Управление"** → **"БД"** или **"MySQL"**
2. Нажмите **"Создать БД"** или **"Новая база данных"**

```
Левое меню:
┌──────────────────────┐
│ ⚙️ Управление        │
│  └─ 🗄️ БД          ◄─ НАЖМИТЕ ЗДЕСЬ
│  └─ 📁 FTP          │
└──────────────────────┘
```

3. Укажите имя БД: `ruldetka_db`
4. Нажмите **"Создать"**

### Создание таблиц:

5. После создания БД вы увидите кнопку **"phpMyAdmin"** или **"Управление"**
6. Нажмите на нее

7. Откроется phpMyAdmin (интерфейс для управления БД)

8. В левой части вы увидите вашу БД `ruldetka_db` - нажмите на нее

9. Найдите вкладку **"SQL"** (в верхнем меню)

10. Нажмите на **"SQL"**

```
phpMyAdmin интерфейс:
┌─────────────────────────────┐
│ 📋 Структура | SQL | Экспорт │
│                            │
│ [SQL запрос здесь]         │
│                            │
│ [Выполнить]                │
└─────────────────────────────┘
```

11. **Важно!** Скопируйте содержимое файла `database/rewards.sql` с вашего компьютера

12. Вставьте этот SQL в поле phpMyAdmin

13. Нажмите **"Выполнить"** или **"Execute"**

14. **Отлично!** Таблицы созданы. Вы должны увидеть сообщение об успехе.

### Проверка:

В левой части phpMyAdmin под `ruldetka_db` должны появиться таблицы:
- `users`
- `boxes`
- `prizes`
- `rewards` ← новая
- `user_rewards` ← новая
- и другие...

## ⚙️ Шаг 6: Конфигурация приложения

### Создание файла .env

1. Вернитесь в панель управления приложением Beget

2. Найдите где можно **создать новый файл**

3. Создайте новый файл с именем `.env`

4. Скопируйте туда это содержимое:

```env
NODE_ENV=production
PORT=3000
DB_HOST=localhost
DB_USER=ваш_логин
DB_PASSWORD=ваш_пароль
DB_NAME=ruldetka_db
JWT_SECRET=your_super_secret_key_change_this_123456789
```

### Где найти данные для БД:

- **DB_USER:** ваш логин Beget
- **DB_PASSWORD:** ваш пароль Beget
- **DB_HOST:** `localhost` или адрес БД (Beget выдаст)
- **DB_NAME:** `ruldetka_db` (как вы назвали БД)

Все эти данные вы можете найти в панели Beget в разделе БД.

## 📞 Что делать если что-то пошло не так?

### Проблема: Ошибка "Cannot find module"

**Решение:**
1. Убедитесь что файл `package.json` загружен
2. Перезагрузите приложение (Restart)
3. Beget автоматически установит зависимости

### Проблема: БД не подключается

**Решение:**
1. Проверьте файл `.env`:
   - DB_HOST правильный
   - DB_USER правильный
   - DB_PASSWORD правильный
   - DB_NAME правильный
2. Убедитесь что БД создана в панели Beget
3. Перезагрузите приложение

### Проблема: Награды не отображаются

**Решение:**
1. Проверьте что файл `database/rewards.sql` был запущен
2. В phpMyAdmin проверьте что таблицы `rewards` и `user_rewards` существуют
3. Убедитесь что файлы `public/js/api.js` и `public/js/main.js` обновлены (с функциями для наград)

### Проблема: Не можете войти в систему

**Решение:**
1. Проверьте что БД доступна
2. Проверьте файл `.env`
3. Может быть JWT_SECRET слишком простой, измените на более сложный

## ❓ Часто задаваемые вопросы

**В: Приложение работает долго загружается, это нормально?**
О: На первый запрос может быть задержка на Beget. Это нормально. После этого будет быстрее.

**В: Можно ли редактировать боксы без кода?**
О: Да! Откройте админ-панель (`https://ruldetka.beget.com/admin`) и редактируйте боксы там.

**В: Где мои пользователи хранятся?**
О: В БД `ruldetka_db` в таблице `users`. Вы можете посмотреть через phpMyAdmin.

**В: Как добавить новую награду?**
О: Можно через API (в админ-панели есть форма) или прямо в phpMyAdmin добавить строку в таблицу `rewards`.

**В: Как узнать сколько монет заработали пользователи?**
О: В phpMyAdmin откройте таблицу `user_rewards` - там все записано.
