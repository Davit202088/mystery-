## 🎯 Как работает система наград?

### Принцип:

1. **Админ создает награды** (за отзыв, за приглашение, ежедневный бонус и т.д.)
2. **Пользователи выполняют действия** (пишут отзыв, приглашают друзей и т.д.)
3. **Система дает монеты за действие** (автоматически или после одобрения)
4. **Пользователи получают награды** и могут использовать монеты для открытия боксов

### Пример:

```
Администратор создает награду:
  - Название: "За отзыв"
  - Монет: 50
  - Тип: review (отзыв)

Пользователь пишет отзыв:
  - Отзыв отправлен на модерацию
  - Админ проверяет и одобряет

Пользователь получает:
  - +50 монет в баланс
  - Награда отмечена как полученная
```

## 🏆 Типы наград

### 1️⃣ **ОТЗЫВ** (review)
```
Условие: Пользователь оставляет отзыв о боксе
Монеты: 50
Частота: Один раз за отзыв
Одобрение: Требуется (админ модерирует)

Пример:
POST /api/reviews
{
  "rating": 5,
  "text": "Отличный бокс! Выиграл iPhone!",
  "boxId": 1
}
```

### 2️⃣ **РЕФЕРАЛ** (referral)
```
Условие: Пользователь приглашает друга
Монеты: 100 (за приглашение) + 50 (когда друг сделал покупку)
Частота: За каждого приглашенного друга
Одобрение: Автоматическое

Пример:
Пользователь А делает реферальную ссылку:
https://ruldetka.ru?ref=user_12345

Пользователь Б переходит по ссылке и регистрируется:
- Пользователь А получает 100 монет

Пользователь Б открывает первый бокс:
- Пользователь А получает еще 50 монет
```

### 3️⃣ **ЕЖЕДНЕВНЫЙ БОНУС** (daily)
```
Условие: Пользователь заходит в приложение каждый день
Монеты: 10 в день
Частота: Раз в день
Одобрение: Автоматическое

Пример:
День 1: +10 монет
День 2: +10 монет
День 7: +10 монет × 7 = 70 монет (за неделю)
```

### 4️⃣ **ДЕЙСТВИЕ** (action)
```
Условие: Пользователь выполняет определенное действие
Монеты: Зависит от действия
Примеры:
  - Первый открытый бокс: 25 монет
  - 5 открытых боксов: 100 монет
  - 10 открытых боксов: 300 монет

Одобрение: Автоматическое (система отслеживает)
```

### 5️⃣ **БОНУС** (bonus)
```
Условие: Специальные события или везение
Монеты: Зависит от события
Примеры:
  - Выиграл 10x приз: 500 монет
  - Выиграл легендарный приз: 1000 монет
  - День рождения: 100 монет

Одобрение: Автоматическое или ручное
```

## 🛠️ Управление наградами для админов

### API Endpoint'ы для админов:

#### 1. Создать новую награду

```bash
POST /api/rewards/admin/create
Authorization: Bearer TOKEN
Content-Type: application/json

{
  "name": "За отзыв",
  "description": "Оставьте отзыв о боксе",
  "type": "review",
  "coins": 50,
  "image": "https://example.com/review.png"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Награда создана",
  "rewardId": "reward_1729xxx_xxx"
}
```

---

#### 2. Обновить награду

```bash
PUT /api/rewards/admin/reward_1729xxx_xxx
Authorization: Bearer TOKEN

{
  "coins": 100,           // Изменить монеты
  "isActive": false       // Отключить награду
}
```

---

#### 3. Выдать монеты вручную

```bash
POST /api/rewards/admin/grant-coins
Authorization: Bearer TOKEN

{
  "targetUserId": "user_1234",
  "coins": 500,
  "reason": "За помощь проекту"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Выдано 500 монет пользователю user_1234",
  "coins": 500,
  "reason": "За помощь проекта"
}
```

---

#### 4. Получить все награды (админ)

```bash
GET /api/rewards/admin/all
Authorization: Bearer TOKEN
```

**Ответ:**
```json
{
  "success": true,
  "rewards": [
    {
      "id": 1,
      "rewardId": "reward_001",
      "name": "За отзыв",
      "type": "review",
      "coins": 50,
      "isActive": true
    },
    {
      "id": 2,
      "rewardId": "reward_002",
      "name": "За приглашение",
      "type": "referral",
      "coins": 100,
      "isActive": true
    }
  ],
  "stats": [
    {
      "type": "review",
      "count": 5,
      "total_coins": 250,
      "claimed_count": 5
```

## 💡 Стратегии использования

### Стратегия 1: ПРИВЛЕЧЕНИЕ НОВЫХ ПОЛЬЗОВАТЕЛЕЙ

```
Основное действие: Приглашение друзей
Награда за приглашение: 100 монет
Награда за активность друга: 50 монет
Максимальная выплата на пользователя: нет лимита

Пример:
- Ты пригласил 10 друзей = 10 × 100 = 1000 монет
- 8 из них открыли боксы = 8 × 50 = 400 монет
- ВСЕГО: 1400 монет заработано!

Преимущество: Вирусный рост и органическое привлечение
```

---

### Стратегия 2: УВЕЛИЧЕНИЕ ЛОЯЛЬНОСТИ

```
Основное действие: Ежедневное посещение
Награда в день: 10 монет
Награда за неделю ежедневных посещений: 100 бонус монет

Пример:
День 1-7: 10×7 = 70 монет
Бонус за 7 дней: +100 монет
ВСЕГО в неделю: 170 монет

Преимущество: Пользователи возвращаются каждый день
```

---

### Стратегия 3: ГЕНЕРИРОВАНИЕ ОТЗЫВОВ

```
Основное действие: Оставление отзыва
Награда за отзыв: 50 монет
Условие: Отзыв должен быть одобрен админом

Пример:
- Отзывы помогают будущим пользователям
- Социальное доказательство
- Пользователи мотивированы писать честные отзывы

Преимущество: SEO, репутация, социальное доказательство
```

---

### Стратегия 4: ДОСТИЖЕНИЯ (ГАМИФИКАЦИЯ)

```
Основное действие: Выполнение достижений
Примеры достижений:
  - Первый бокс: 25 монет
  - 5 боксов: 100 монет
  - 10 боксов: 300 монет
  - 50 боксов: 1000 монет
  - Выиграл 10x приз: 500 монет

Преимущество: Долгосрочное взаимодействие с платформой
```

## 🎯 SQL Запросы для управления

### Получить все награды
```sql
SELECT * FROM rewards WHERE isActive = 1;
```

### Получить награды определенного типа
```sql
SELECT * FROM rewards WHERE type = 'referral';
```

### Сколько монет получено каждым пользователем за награды
```sql
SELECT
  u.username,
  COUNT(ur.id) as rewards_count,
  SUM(r.coins) as total_coins
FROM user_rewards ur
JOIN users u ON ur.userId = u.id
JOIN rewards r ON ur.rewardId = r.id
GROUP BY u.id
ORDER BY total_coins DESC;
```

### Выданные админом монеты
```sql
SELECT
  u.username as admin,
  target.username as target_user,
  ag.coins,
  ag.reason,
  ag.timestamp
FROM admin_grants ag
JOIN users u ON ag.adminId = u.userId
JOIN users target ON ag.targetUserId = target.userId
ORDER BY ag.timestamp DESC;
```

### Отключить все награды определенного типа
```sql
UPDATE rewards SET isActive = 0 WHERE type = 'review';
```

### Создать новую награду через SQL
```sql
INSERT INTO rewards (rewardId, name, description, type, coins, image)
VALUES (
  'reward_new_001',
  'Новая награда',
  'Описание награды',
  'action',
  200,
  'https://example.com/image.png'
);
```

## 🚀 Внедрение в приложение

```html
<section id="rewards" class="rewards-section">
  <h2>🎁 Заработайте монеты!</h2>
  <div id="rewardsContainer" class="rewards-grid">
    <!-- Награды загружаются здесь -->
  </div>
</section>
```

### 2. В JavaScript (main.js)
```javascript
// Загрузить награды
async function loadRewards() {
  const rewards = await fetch('/api/rewards/available', {
    headers: {'Authorization': `Bearer ${token}`}
  }).then(r => r.json());

  displayRewards(rewards.rewards);
}

// Получить награду
async function claimReward(rewardId) {
  const result = await fetch(`/api/rewards/claim/${rewardId}`, {
    method: 'POST',
    headers: {'Authorization': `Bearer ${token}`}
  }).then(r => r.json());

  if (result.success) {
    showNotification(`✅ +${result.coins} монет за "${result.rewardName}"`);
  }
}
```

```html
  <table id="rewardsTable">
    <!-- Таблица наград -->
  </table>
```
