### При развертывании на Beget:

1. **Загрузить файлы через FTP/SFTP:**
   - Загрузить `routes/rewards.js`
   - Заменить `public/index.html`
   - Заменить `public/js/api.js`
   - Заменить `public/js/main.js`
   - Заменить `public/css/styles.css`

2. **Создать таблицы в БД:**
   ```bash
   # Подключитесь к MySQL на Beget
   mysql -h mysql.beget.ru -u username -p database_name < rewards.sql
   ```

3. **Перезагрузить приложение:**
   ```bash
   # Через Beget панель или консоль
   pm2 restart all
   ```

4. **Проверить что все работает:**
   - Откройте https://yourdomain.com
   - Зарегистрируйтесь
   - Найдите секцию "Заработайте монеты"
   - Попробуйте получить награду

```bash

ls -la routes/rewards.js

# 4. Открыть в браузере
# http://localhost:3000
```
