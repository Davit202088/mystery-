# 🎁 Интеграция Системы Наград - RULDETKA v1.0.0

## 📋 Обзор

Система наград полностью интегрирована в главное приложение RULDETKA. Пользователи теперь могут:

✅ **Видеть доступные награды** и их требования
✅ **Получать награды** за различные действия (отзывы, рефералы, дневные входы)
✅ **Просматривать историю** всех полученных наград с монетами
✅ **Делиться реферальной ссылкой** с друзьями в Telegram, WhatsApp, ВКонтакте
✅ **Копировать реферальную ссылку** одним кликом

### 2. **UI Компоненты (public/index.html)**

#### Новая секция "Заработайте монеты"
- Отображается между Лидербордом и Features
- Показывает все доступные награды в виде карточек
- Каждая карточка содержит:
  - Иконка награды (зависит от типа)
  - Название и описание
  - Тип награды (Отзыв, Реферал, Ежедневный и т.д.)
  - Количество монет
  - Кнопка "Получить" (или "✓ Получено" если уже получена)

#### Модальное окно "История наград"
- Открывается кнопкой в секции наград
- Показывает все полученные награды пользователем
- Отображает:
  - Иконку награды
  - Название и тип
  - Количество монет
  - Время получения
- В заголовке модала показывается общее количество полученных монет

#### Реферальная программа
- Новый пункт меню "Реферал" для залогиненных пользователей
- Модальное окно с:
  - **Реферальной ссылкой** - уникальная ссылка для приглашения друзей
  - **Кнопка копирования** - быстрое копирование в буфер обмена
  - **Информация о вознаграждении**:
    - 100 монет за приглашение друга
    - 50 монет когда друг сделает первую покупку
    - Без лимитов на количество приглашений
  - **Кнопки быстрого поделиться**:
    - 📱 Telegram
    - 📱 WhatsApp
    - 📱 ВКонтакте

## 🔄 Поток работы

### Для пользователя:

1. **Регистрация/Вход** в приложение
2. **Просмотр доступных наград** в секции "Заработайте монеты"
3. **Получение награды** кнопкой "Получить"
   - Система проверяет может ли пользователь получить награду
   - Добавляет монеты на баланс
   - Показывает уведомление об успехе
   - Перезагружает список наград (уже полученные становятся недоступными)
4. **Просмотр истории** кнопкой "История наград"
   - Видит все полученные награды и монеты
5. **Приглашение друзей** через реферальную программу
   - Открывает модал "Реферал" из меню
   - Копирует реферальную ссылку
   - Делится в Telegram, WhatsApp или ВКонтакте

### Для администратора:

1. **В админ-панели** `/admin.html` управляет наградами
2. **Создает новые награды** (POST `/api/rewards/admin/create`)
3. **Обновляет награды** (PUT `/api/rewards/admin/:rewardId`)
4. **Выдает монеты вручную** (POST `/api/rewards/admin/grant-coins`)
5. **Просматривает статистику** (GET `/api/rewards/admin/all`)

## 🎮 Примеры использования

### Сценарий 1: Новый пользователь получает награду

```
1. Пользователь видит награду "За первый открытый бокс" (25 монет)
2. Нажимает кнопку "Получить"
3. Система добавляет 25 монет на его баланс
4. Появляется уведомление: "✅ Получено 25 монет за За первый открытый бокс!"
5. Кнопка меняется на "✓ Получено" и становится неактивной
```

### Сценарий 2: Пользователь приглашает друга

```
1. Пользователь открывает меню "👤 Реферал"
2. Видит свою уникальную ссылку: "https://ruldetka.ru?ref=user_123"
3. Нажимает "Копировать" или выбирает "Telegram"
4. Ссылка копируется в буфер обмена или открывается Telegram
5. Пользователь отправляет ссылку другу
6. Друг переходит по ссылке и регистрируется
7. Оригинальный пользователь получает 100 монет за приглашение
8. Когда друг сделает покупку, получает еще 50 монет
```

### Сценарий 3: Просмотр истории наград

```
1. Пользователь нажимает "История наград"
2. Открывается модал со списком всех полученных наград
3. В заголовке видит: "Всего получено: 450 монет"
4. Видит историю:
   - За первый открытый бокс (25 монет) - 2 часа назад
   - За приглашение (100 монет) - 1 день назад
   - Ежедневный бонус (10 монет) - 30 минут назад
   - ...и так далее
```

## 📝 Данные в БД

### Таблица rewards
```sql
id                INT PRIMARY KEY
rewardId          VARCHAR(255) UNIQUE -- "reward_review_001"
name              VARCHAR(255)       -- "За отзыв"
description       TEXT               -- "Оставьте отзыв о боксе"
type              ENUM(...)          -- "review", "referral", "daily", "action", "bonus"
coins             INT                -- 50
image             VARCHAR(255)       -- URL изображения
isActive          BOOLEAN            -- true/false
createdAt         TIMESTAMP
updatedAt         TIMESTAMP
```

### Таблица user_rewards
```sql
id                INT PRIMARY KEY
userId            INT                -- foreign key -> users(id)
rewardId          INT                -- foreign key -> rewards(id)
claimedAt         TIMESTAMP          -- когда получена
UNIQUE KEY (userId, rewardId)        -- можно получить только 1 раз
```

### Таблица reward_logs
```sql
id                INT PRIMARY KEY
userId            INT
rewardId          INT
action            VARCHAR(50)        -- "claim", "grant"
amount            INT                -- количество монет
timestamp         TIMESTAMP
```

## 🚀 Развертывание

### На Beget:

Все файлы уже готовы. При развертывании на Beget:

1. Загрузите **routes/rewards.js** на сервер
2. Загрузите обновленные **public/index.html**, **public/js/main.js**, **public/js/api.js**, **public/css/styles.css**
3. Запустите **database/rewards.sql** для создания таблиц
4. Перезагрузите приложение

### Локально:

```bash
# Убедитесь что MySQL запущена
mysql -u root -p < database/rewards.sql

# Запустите сервер
npm start

# Откройте в браузере
http://localhost:3000
```
