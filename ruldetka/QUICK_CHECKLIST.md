# ⚡ Быстрый чек-лист развертывания на Beget

## 🚀 5 минут до запуска

### ✅ Фаза 1: Подготовка (2 мин)

- [ ] Скопировали все файлы проекта в папку
- [ ] Выполнили `git init` и `git add .`
- [ ] Создали первый коммит: `git commit -m "Initial"`

### ✅ Фаза 2: На Beget (3 мин)

- [ ] Создали Node.js приложение в панели Beget
- [ ] Скопировали Git URL из Beget
- [ ] Выполнили `git push -u beget main`
- [ ] Создали MySQL БД `ruldetka_test`
- [ ] Получили реквизиты БД (хост, пользователь, пароль)

### ✅ Фаза 3: Конфигурация (5 мин)

```bash
# В SSH терминале Beget:

# 1. Перейти в папку
cd /home/username/приложение/ruldetka-test

# 2. Создать .env файл
cat > .env << 'EOF'
NODE_ENV=production
PORT=3000
APP_URL=https://ваш-домен.beget.com
DB_HOST=localhost
DB_USER=ruldetka_user
DB_PASSWORD=ВашПароль
DB_NAME=ruldetka_test
JWT_SECRET=ваш_случайный_ключ_здесь
YOOKASSA_SHOP_ID=later
YOOKASSA_SECRET_KEY=later
EOF

# 3. Установить зависимости
npm install --production

# 4. Инициализировать БД
node config/database.js

# 5. Загрузить примеры
mysql -u ruldetka_user -p ruldetka_test < database/seed.sql
```

### ✅ Фаза 4: Запуск (1 мин)

- [ ] В панели Beget нажмите "Запустить" для приложения
- [ ] Дождитесь статуса "Работает" ✅

### ✅ Фаза 5: Проверка (2 мин)

```bash
# Проверить что работает
curl https://ваш-домен.beget.com/health

# Должно вернуть:
# {"status":"OK","timestamp":"..."}
```

- [ ] Открыли главную страницу в браузере
- [ ] Зарегистрировались как тестовый пользователь
- [ ] Открыли админ-панель (`/admin.html`)

## 🔑 Быстрые команды

### Перезагрузить приложение:
```bash

npm restart
# или через панель: Приложение → Перезагрузить
```

### Проверить логи:
```bash
# Панель Beget: Приложение → Логи
# или SSH:
tail -f logs/error.log
```

### Обновить код после изменений:
```bash
cd C:\ruldetka-deploy
git add .
git commit -m "Update: описание"
git push beget main
```

### Сделать себя админом:
```bash

UPDATE users SET role = 'admin' WHERE username = 'ваше_имя';
```

## ⚠️ Частые ошибки и решения

| Ошибка | Решение |
|--------|---------|
| "Cannot find module" | `npm install --production` |
| "connect ENOENT" | Проверьте .env и реквизиты БД |
| "Port 3000 in use" | Смените PORT в .env |
| "Приложение не запускается" | Посмотрите логи в панели Beget |
| "500 ошибка на API" | Проверьте JWT_SECRET в .env |

## 📞 Когда понадобится помощь

1. **Beget не создает приложение?** → support@beget.com
2. **Ошибка при git push?** → Проверьте SSH ключ или используйте HTTPS
3. **БД не подключается?** → Проверьте хост и пароль в .env
4. **Приложение зависает?** → Перезагрузитесь в панели

## ✨ После успешного развертывания

1. **Протестировать все функции**
   - Регистрация/вход
   - Открытие боксов
   - Админ-панель

2. **Настроить вероятности боксов**
   - Откройте админ-панель
   - Раздел: "⚙️ Управление вероятностями"
   - Отредактируйте % для каждого приза

3. **Интегрировать платежи**
   - Получить ключи Яндекс.Касса
   - Добавить в .env
   - Тестировать платежи

4. **Подключить свой домен** (когда будет готово)
   - Следовать `DEPLOYMENT.md`
   - Настроить DNS
   - Готово!
