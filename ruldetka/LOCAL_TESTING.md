## Как протестировать в браузере

### 1. Откройте главную страницу

Откройте в браузере:
```
http://localhost:3000
```

Вы увидите:
- Главную страницу с рулеткой
- 3 бокса (Starter, Deluxe, Premium)
- Лидерборд
- Кнопки "Вход" и "Регистрация"

### 2. Войдите в систему

1. Нажмите кнопку **"Вход"** в правом верхнем углу
2. Введите тестовые данные:
   - Email: `test@example.com`
   - Пароль: `password123`
3. Нажмите **"Вход"**
4. Вы должны увидеть ваше имя пользователя вместо кнопки "Вход"

### 3. Просмотрите профиль

1. Нажмите на ваше имя пользователя в правом верхнем углу
2. Вы увидите:
   - Баланс: 5000 ₽
   - Открыто боксов: 0
   - Потрачено: 0 ₽

### 4. Просмотрите боксы

1. Прокрутите страницу вниз
2. Вы увидите 3 бокса:
   - **Starter Box** - 499 ₽ (3 приза)
   - **Deluxe Box** - 1999 ₽ (4 приза)
   - **Premium Box** - 4999 ₽ (6 призов)

### 5. Откройте админ-панель

Откройте в новой вкладке:
```
http://localhost:3000/admin.html
```

Вы увидите:
- Статистику (пользователи, боксы, доход)
- Управление боксами
- Управление призами и вероятностями
- Логи системы

## Тестирование API

### 1. Health Check

```bash
curl http://localhost:3000/health
```

**Ожидаемый результат:**
```json
{
  "status": "OK",
  "timestamp": "2025-10-26T10:33:55.986Z"
}
```

### 2. Получить все боксы

```bash
curl http://localhost:3000/api/boxes
```

**Ожидаемый результат:**
Список из 3 боксов с призами

### 3. Вход в систему

```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"password123"}'
```

**Ожидаемый результат:**
```json
{
  "success": true,
  "token": "eyJhbGc...",
  "user": {
    "userId": "user_test_001",
    "email": "test@example.com",
    "username": "testuser",
    "firstName": "Test",
    "lastName": "User"
  }
}
```

### 4. Регистрация нового пользователя

```bash
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email":"newuser@example.com",
    "password":"password123",
    "username":"newuser",
    "firstName":"New",
    "lastName":"User"
  }'
```

## Остановка сервера

Чтобы остановить сервер:

```bash
# Найти процесс
ps aux | grep "node server.js"

# Убить процесс
pkill -f "node server.js"

# Или используйте Ctrl+C если сервер запущен в терминале
```

---

## Запуск сервера заново

```bash
cd ruldetka
npm start
```

Сервер запустится на порту 3000.

## Возможные проблемы:

### Порт 3000 занят

```bash
# Найти что использует порт 3000
lsof -i :3000

# Убить процесс
kill -9 <PID>
```

### База данных не создается

```bash
# Удалить старую БД и создать заново
rm ruldetka.db
npm start
```
