## 🔑 Ключевые файлы проекта

### Для запуска:
- **`server.js`** - главный сервер (Express + WebSocket)
- **`package.json`** - зависимости и скрипты
- **`.env`** - переменные окружения

### Для фронтенда:
- **`public/index.html`** - главная страница
- **`public/admin.html`** - админ-панель
- **`public/css/styles.css`** - стили
- **`public/js/main.js`** - логика
- **`public/js/api.js`** - API клиент

### Для бэкенда:
- **`routes/auth.js`** - аутентификация
- **`routes/boxes.js`** - боксы
- **`routes/payment.js`** - платежи
- **`routes/admin.js`** - админ API
- **`config/database.js`** - БД

## 🎛️ Управление приложением

### Если приложение не работает:

1. **Проверить статус в Beget панели**
   - Приложение → Статус

2. **Посмотреть логи**
   - Приложение → Логи

3. **Перезагрузить**
   - Приложение → Перезагрузить

4. **Проверить .env файл**
   - Все переменные установлены?
   - Пароль БД правильный?

5. **Проверить БД**
   ```bash
   mysql -u ruldetka_user -p ruldetka_test
   SHOW TABLES;
   SELECT COUNT(*) FROM boxes;
   ```

## 💡 Полезные команды

### На локальной машине:

```bash
# Запустить локально для тестирования
cd C:\Users\user\ruldetka
npm install
node server.js
# Откройте http://localhost:3000

# Создать коммит и загрузить на Beget
git add .
git commit -m "Update: описание изменений"
git push beget main
```

### На Beget (в SSH):

```bash
# Инициализировать БД
node config/database.js

# Загрузить примеры
mysql -u ruldetka_user -p ruldetka_test < database/seed.sql

# Установить зависимости
npm install --production

# Перезагрузить приложение
npm restart
```
